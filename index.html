MY STORY

I'm not just building projects. I'm building myself.

Being a science student always dragged my curiosity into technology. I didn't started my journey with coding / programming. Initially I learned Graphics Designing, explored tools and softwares. Then I started working as a remote graphics designer + social media manager at Creative Bees Marketing Agency. That was the beginnig of my journey in tech.

My first connection with the digital world came through design. I started exploring graphic design and UI/UX, learning how colors, layouts, typography, and visual experiences can turn an idea into something people can actually see and interact with.

C-programming was in syllabus and ofcourse we have to learn it i studied it and worked hard. And then I got to know about web development.

From there, I moved into web development. HTML and CSS helped me understand how websites are structured and styled, while JavaScript introduced me to interaction and functionality.

Instead of only following tutorials, I started building things. Some were small experiments, while others became real projects. One of the biggest steps for me was building FuelFlow, a petrol pump management system with dashboards, sales, inventory, reports, and other real-world features.

Every project taught me something different. More importantly, every bug taught me that not knowing something is not a reason to stop — it's a reason to learn. I never knew about Git & Github at beginning but I learned about it and started implementing on my every projects, practices.

Today, I'm continuing that journey by learning Python, improving my JavaScript skills, exploring backend development, and moving toward software engineering and AI/ML specialist.

I don't consider myself a developer. I'm still learning, still building, and still figuring things out. And that's exactly what this portfolio is here to document.
